# MIMO Capstone Project: Fourier Series in Radar Imaging  
**Application of Discrete Fourier Transform in Multiple-Input Multiple-Output Radar Systems**  

## 📌 Project Overview  
This project demonstrates how Fourier series and Discrete Fourier Transform (DFT) enhance resolution in MIMO radar imaging systems compared to traditional phased array radars.
